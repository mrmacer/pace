# Instructions for AI agents (Codex and others)

This project keeps shared notes so every agent, on any machine, has the full
context. Follow the same instructions as Claude: see [CLAUDE.md](CLAUDE.md).

In short:
- **Before starting:** read `docs/agent-notes/CONTEXT.md`, then `docs/agent-notes/LOG.md`.
- **When done:** add an entry at the top of `docs/agent-notes/LOG.md` (quote the
  requests word for word; record your decisions, changes, verification, and
  open items) and update `CONTEXT.md` if anything it describes changed.
- **This repo is public:** never write student information, email addresses,
  or secrets anywhere in it.
